# CLAUDE.md — MacPlayer

## Project Overview

MacPlayer is a macOS/Windows desktop IPTV player for Stalker Portal-based services. Users configure portals (URL + MAC addresses), load the channel list, and watch live TV. Built with PySide6 (Qt) and python-vlc.

## How to Run

```bash
python main.py
```

Requires VLC installed system-wide and Python 3.10+.

## Architecture

```
UI layer (ui/)  →  Worker threads (worker.py)  →  STB API (stb.py)
                         ↕
               Config / data models (config.py)
```

### Key files

| File | Responsibility |
|---|---|
| `main.py` | Creates `QApplication`, applies dark palette, launches `MainWindow` |
| `config.py` | `Portal` dataclass + `Config` manager; persists to `~/.macplayer/config.json` |
| `stb.py` | All Stalker Portal HTTP calls: URL discovery, handshake, channels, EPG, stream links |
| `worker.py` | Three `QThread` subclasses that run blocking I/O off the main thread |
| `ui/main_window.py` | Orchestrates toolbar, portal CRUD, channel loading, stream resolution + failover |
| `ui/channel_panel.py` | Channel list with genre filter dropdown |
| `ui/player_widget.py` | Embeds VLC; monitors stream health; emits `playback_failed` on errors |
| `ui/epg_widget.py` | Sidebar EPG display tied to the currently selected channel |
| `ui/portal_dialog.py` | Dialog for creating/editing portals (TXT import, MAC testing) |

### Worker threads

- **`ChannelLoader`** — iterates MACs, does URL discovery → auth → `get_all_channels` + `get_genres`, emits `finished(channels, genres)` or `error(msg)`
- **`StreamResolver`** — resolves stream URL for a channel. Takes `skip_macs` set to avoid already-tried MACs. Emits `trying(mac)` before each attempt, `resolved(url, mac)` on success
- **`EPGLoader`** — fetches 24-hour EPG data for the active channel

Workers communicate back to the UI exclusively via Qt signals — never call UI methods directly from a thread.

### MAC failover flow

1. Channel selected → `_tried_macs = {}`, `StreamResolver` started
2. Resolver emits `trying(mac)` → player overlay shows which MAC is being tried
3. Resolver emits `resolved(url, mac)` → `_tried_macs.add(mac)`, `play_url()` called
4. `PlayerWidget._monitor()` runs every second, watching VLC state via:
   - **VLC event callbacks** (`MediaPlayerEncounteredError`, `MediaPlayerEndReached`, `MediaPlayerStopped`) — set `_vlc_error_flag`, picked up by `_monitor` on Qt thread
   - **State polling** — `Stopped`/`Ended` → fail; `Buffering` > 20 s → fail; `Opening` > 12 s → fail
   - **Freeze detection** — `get_time()` not advancing for 15 s → fail
5. On failure: `playback_failed` signal → `_on_playback_failed` in `MainWindow`
6. `MainWindow` calls `_start_stream_resolver(portal)` with updated `skip_macs=_tried_macs`
7. Repeat until all MACs exhausted → error message shown

### TXT import (portal dialog)

Regex-based extraction from one or more `.txt` files:
- URL pattern: `http://…/c/` — first match fills the URL field (if empty)
- MAC pattern: `XX:XX:XX:XX:XX:XX` — all matches added to MAC list (deduped)

### Test Connection (portal dialog)

Checks **all** MACs sequentially using the real Stalker Portal API. Colors each entry green/red with expiry date. Offers to remove invalid MACs at the end.

### Config persistence

`~/.macplayer/config.json` stores portals list and last-used volume. `Config.save()` is called automatically on every mutation and on window close.

## Conventions

- All UI styling via inline QSS strings defined as module-level constants.
- The dark palette is set application-wide in `main.py`; widget-level overrides use QSS only.
- `stb.py` functions return `None` silently on any error — callers must check for `None`.
- `_tried_macs` accumulates across the full playback session for a channel — it is only reset when a new channel is selected.
- Do not block the Qt main thread — any network call belongs in a `QThread` worker.
- VLC event callbacks fire on VLC's internal thread; only set a flag there, handle it on the Qt thread in `_monitor`.

## Building

```bash
# macOS
./build.sh          # → dist/MacPlayer.app + dist/MacPlayer.dmg

# Windows
build.bat           # → dist/MacPlayer/MacPlayer.exe + dist/MacPlayer-windows.zip
```

Icons are generated by `create_icon.py` (requires Pillow) and are not committed to git.
